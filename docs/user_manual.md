# NL2SQL 智能查询系统 - 用户手册

## 1. 系统简介

NL2SQL 智能查询系统允许用户通过自然语言提问的方式查询数据库，系统自动将自然语言转换为 SQL 查询语句并返回结果。无需编写 SQL，即可轻松获取数据。

## 2. 环境准备

### 2.1 系统要求
- 浏览器：Chrome 90+ / Edge 90+ / Firefox 90+
- 后端服务已部署并运行
- Ollama 模型服务已启动

### 2.2 访问系统
在浏览器中访问系统地址（默认 http://localhost:5173）

## 3. 登录与注册

### 3.1 用户注册
1. 打开系统页面，点击"注册"标签
2. 输入用户名（至少 3 个字符）
3. 输入密码（至少 6 个字符）
4. 点击"注册"按钮

### 3.2 用户登录
1. 在登录页面输入用户名和密码
2. 点击"登录"按钮
3. 登录成功后自动跳转到主对话页面

## 4. 数据源管理

### 4.1 添加数据源
1. 点击左侧菜单"设置"进入数据源管理页面
2. 点击"新增数据源"按钮
3. 填写数据源信息：
   - **名称**: 数据源的显示名称
   - **类型**: 选择 mysql（目前仅支持 MySQL）
   - **主机**: 数据库服务器地址（如 localhost 或 192.168.1.100）
   - **端口**: 数据库端口（MySQL 默认 3306）
   - **数据库名**: 要查询的数据库名称
   - **用户名**: 数据库用户名
   - **密码**: 数据库密码
4. 点击"测试连接"验证配置是否正确
5. 点击"确定"保存数据源

### 4.2 测试连接
- 在数据源列表中，点击"测试"按钮
- 系统会尝试连接数据库并返回结果
- 成功显示绿色提示，失败显示红色错误信息

### 4.3 删除数据源
- 在数据源列表中，点击"删除"按钮
- 确认删除操作

## 5. 自然语言查询

### 5.1 基本使用
1. 在主对话页面，确认右上角数据源选择正确
2. 在底部输入框中输入自然语言问题
3. 按 Enter 或点击发送按钮
4. 等待系统返回 SQL 和查询结果

### 5.2 示例问题

**简单查询**:
- "查询所有用户"
- "显示所有产品信息"

**条件过滤**:
- "查询年龄大于25岁的用户"
- "查找状态为已完成的订单"
- "显示价格在100到500之间的产品"

**聚合统计**:
- "统计每个部门的用户数量"
- "计算每个月的订单总金额"
- "查询各产品的平均评分"

**排序与 TOP-N**:
- "查询消费金额最高的10个用户"
- "显示最近的5笔订单"
- "按年龄从大到小排列用户"

**关联查询**:
- "查询每个订单对应的用户姓名"
- "显示每个用户购买的产品列表"
- "查询购买了手机的用户的联系方式"

**模糊匹配**:
- "查询姓张的用户"
- "查找包含'手机'的产品"

### 5.3 查询结果
- **SQL 展示**: 系统会显示生成的 SQL 语句（语法高亮）
- **结果表格**: 以表格形式展示查询结果
- **结果统计**: 显示返回的行数和执行时间

### 5.4 表结构浏览
- 在对话页面右侧可以浏览当前数据源的表结构
- 展开表名可以查看所有字段及其类型
- 点击刷新按钮可以更新表结构信息

## 6. 常见问题

### Q: 查询结果不正确怎么办？
A: 尝试更具体地描述你的问题，明确指出表名和字段名。例如，将"查一下数据"改为"查询用户表中年龄大于25岁的用户姓名"。

### Q: 系统提示"无法理解该查询"？
A: 可能是问题过于复杂或涉及系统不支持的操作。尝试简化问题，或拆分为多个简单查询。

### Q: 查询很慢？
A: 首次查询需要调用 AI 模型生成 SQL，可能需要 5-10 秒。后续相同类型的查询会更快。

### Q: 数据源连接失败？
A: 检查以下项目：
- 数据库服务是否正在运行
- 主机地址和端口是否正确
- 用户名和密码是否正确
- 防火墙是否允许连接
- 数据库用户是否有 SELECT 权限

### Q: 为什么不能执行 INSERT/UPDATE/DELETE？
A: 出于安全考虑，系统只允许只读查询（SELECT），禁止任何数据修改操作。

## 7. 安全说明

- 所有查询均为只读操作，不会修改数据库数据
- 查询结果自动限制为最多 100 行
- 查询超时时间为 10 秒
- 所有查询操作均有审计日志记录
- 密码使用 BCrypt 加密存储
- 通信使用 JWT 令牌认证
